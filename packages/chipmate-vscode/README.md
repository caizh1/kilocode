<h1 align="center">ChipMate</h1>

<p align="center">
  <strong>An AI coding assistant for embedded C/C++ development.</strong><br>
  Build features, inspect codebases, automate routine engineering tasks, and work with local repositories from VS Code.
</p>

## Key Features

- **Code Generation:** Generate and revise code from natural language instructions.
- **Inline Autocomplete:** Get AI-assisted code suggestions while editing.
- **Task Automation:** Run coding tasks, terminal commands, and repository workflows from chat.
- **Codebase Understanding:** Ask questions about your project and inspect relevant source context.
- **Custom Modes:** Use planning, coding, debugging, and review-oriented agent modes.

## Project Baseline

ChipMate starts its own extension version line at `0.0.1`.
This branch is based on the ChipMate `v7.3.42` tag.

## Get Started

1. Install the ChipMate VS Code extension from the local VSIX package.
2. Open a repository in VS Code.
3. Start a chat from the ChipMate activity bar and ask it to build, fix, or explain code.

If you want to contribute or modify the extension locally, see the repository development notes for build and setup instructions.
