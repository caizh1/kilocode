# 中国专利试运行数据一键导入说明

本包包含 CNIPA `2023-10-03` 周包中的第一个内部子包，共 2000 件中国发明专利申请全文。它是 `supplemental` 局部语料，不是中国历史全量库，也不包含法律状态、向量或重排模型。

## 前提

- 已在 Linux x86-64 主机安装并启动 ChipMate Patent Server 0.1.2。
- Patent Server 的 `.env` 已包含：

  ```dotenv
  PATENT_JURISDICTIONS=CN
  PATENT_ALLOW_INCOMPLETE_CORPUS_SEARCH=1
  ```

- 数据盘至少保留 10 GiB 可用空间。
- 不要把本包解压到 `/srv/chipmate-patent/drop/`；脚本会安全地完成复制、校验和原子入队。

## 一键导入

先校验并解压数据包：

```bash
sha256sum -c chipmate-cn-patent-data-20231003-1-001.tar.gz.sha256
tar -xzf chipmate-cn-patent-data-20231003-1-001.tar.gz
cd chipmate-cn-patent-data-20231003-1-001
sha256sum -c MANIFEST.sha256
```

执行一条导入命令，参数是 Patent Server 0.1.2 的解压部署目录：

```bash
sudo ./import-patents.sh /opt/chipmate-patent-server-offline-0.1.2-linux-amd64
```

脚本会完成以下工作：

1. 校验整个数据包和 997 MiB 官方内部 ZIP 的 SHA-256。
2. 确认服务解析器为 `cnipa-st36-compatible-v3`。
3. 暂停常驻导入器，避免重复抢占同一文件。
4. 把 ZIP 与 manifest 复制到隐藏暂存目录并再次校验。
5. 按“manifest 先、ZIP 后”的顺序原子放入 `drop/`。
6. 执行导入并要求 2000 条发现、2000 条接受、0 条拒绝。
7. 恢复常驻导入器并核对在线语料水位。

成功时会显示 `status: published`；重复导入相同哈希时会显示 `status: duplicate`，两者都不会覆盖已有历史版本。

## 接入 ChipMate 1.2.7

在 ChipMate 1.2.7 打开“设置 → 专利中心”，填写：

```text
https://内网Patent-Server域名:6020
```

保存后执行连接检查，再运行 Patent Radar。由于本包只是局部周包，服务状态应保持 `DEGRADED`，Radar 必须输出 `insufficient-evidence`，不能据此声称没有更早专利或不存在侵权风险。
