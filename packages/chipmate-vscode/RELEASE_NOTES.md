# ChipMate 1.1.0

相较 1.0.19：

- 修复 1.1.0 启动服务器时遗漏 Skill Market 运行时服务、导致 CLI 在数据库迁移完成后立即退出的问题。
- 在索引服务启动前迁移 1.0.19 的全局与项目配置、认证、模型选择、VS Code 状态和会话中的旧 provider 标识，保留 Embedding API Key、端点、模型、维度、文档目录及其他索引设置；当前 ChipMate 数据优先，旧数据只补缺并保留可恢复备份。
- API Key 单独变化时现在只重建连接并重新验证 Embedding 服务；向量空间指纹一致时继续使用原 active generation，并仅扫描新增或修改文件，不再强制清空 Document RAG 缓存和重复嵌入。
- 完成产品命名空间隔离：源码、包、命令、配置、环境变量、资源与构建流程统一使用 ChipMate 标识，不再携带或访问上游产品的运行时入口与配置路径。
- 同步上游 `v7.4.21` 的核心、SDK 与服务端改进，并保留 ChipMate 扩展、索引、Agent Manager 和内网离线能力的完整兼容。
- 文档索引现在会持续跟踪文件新增、修改与删除，并在后台索引或重建期间自动收敛最新变更，减少手动刷新与重复重建。
