# ChipMate 发行说明

## 1.2.19

相较 1.2.15，本次为 1.2.19 累计更新重打包，包含以下变化：

- 新增“未来风”皮肤，在“设置 → 显示”手动启用电青与洋红双色霓虹边框、会话标签和输入框；覆盖插件自绘页面，提供关闭、柔和、沉浸动效，保留原皮肤为默认并遵循减少动态效果设置。
- 输入工具栏支持文件、图片、编辑器选区和文件夹引用，可查看、移除上下文；底栏按模式、模型、推理档位排列，支持窄侧栏、长模型名和多会话标签。切换皮肤保留输入组件和会话状态，忽略切换草稿或修改输入后的迟到引用结果。
- 收紧未来风空输入框高度，按容器宽度切换紧凑单排或双排底栏；上下文改为引用图标与数量。页面、输入框和当前标签使用独立细线霓虹素材，移除侧栏重复导航，并修复分栏设置导航文字隐藏与弹层过大问题。原版继续作为安装和升级默认，已手动保存的皮肤选择保留。
- 修复未来风点击新建会话或历史入口时切走聊天侧栏的问题；恢复模型后直接可见的推理档位，不再由上下文控件占据第三个选择器位置。
- 将 `/spec` 简化为在当前对话中按需加载的 SDD Skill，跟随当前模型选择，移除专用阶段调度、预算检查和批准状态机；取消固定文档工具、图页数量和强制子任务要求，保留来源证据、中文任务材料及基线、计划、交付三次确认指引。已有显式模型覆盖继续生效，旧任务保留为历史资料。
- 修复远程连接两端时钟不一致导致 Spec 流程介绍打不开的问题，增加加载、失败原因和重试反馈，并保持取消、迟到响应和重复打开的隔离。
- 新增独立 `word_to_images` 工具，将已有 Word 按页转为 PNG 以查看公式、流程图和复杂表格；页面卡片显示真实页码并使用原生图片预览。该工具不修改原 Word、不走旧目录刷新或页码回填流程，需要支持独立转图接口的 ChipMate Server。
- Linux x64 包内置 PDF 文本提取程序、运行依赖和中文编码数据，修复缺少 `pdftotext` 导致 PDF 文档索引不可用的问题。
- Windows/Linux 为手动验证候选包，不进入自动更新渠道。真实目标机安装、完整原生引用发送及模型遵循仍待验收；既有低配启动长任务超标继续单列，不以构建通过代替业务验收。

## 1.2.12

相较 1.2.8（内网累计更新）：

- 修复刚安装插件、尚未创建对话时打开主编辑区出现空白的问题；主编辑区会先建立可用会话，并与侧栏保持同一会话身份。
- 修复对话中或模型持续输出时切换主编辑区/侧栏可能出现重复标签、丢失草稿、旧界面继续写入或流式内容不同步的问题；交接现在保持唯一写入方并连续同步当前回复。
- 修复关闭主编辑区、立即重开以及连续往返切换时的恢复竞态；同一会话始终只保留一个主编辑区标签，草稿与会话状态可稳定恢复。
- 修复 DeepSeek 官方模型在长批次中返回空内容、非 JSON、字段缺失或越界工程评分时导致扫描整体失败的问题；扫描现在隔离问题批次、保留有效结果，并将无法可靠复核的候选降级为观察项。
- 全项目机制归并改用更小的确定性批次，并持续保存进度与检查点；取消后可从已保存进度继续，Patent Server 检索会逐条查询、去重和融合，避免触发 OpenSearch 子句上限。
- 同一工作区快速重复启动相同范围和模型的扫描时，原子复用同一后台任务，避免产生双任务、重复模型调用和竞态结果。
- 工作区已有扫描与新请求的范围或模型不一致时明确阻止启动；模块扫描不再静默恢复为全项目任务，用户选择的扫描边界保持一致。
- 扫描界面会等待启动或取消回执并锁定重复操作，只接受最新请求的响应；取消失败显示真实错误，取消成功后可以立即重新开始独立扫描。
- 专利中心仍属于实验性技术预检；真实 Gold Set、完整历史语料和内网 Linux 目标机验收完成前，不得把结果解释为完整检索、授权判断或不侵权结论。

- ChipMate 市场改用 Microsoft AD LDAP 用户名和密码登录；人员登录、收藏、安装记录同步和发布操作不再读取或发送 AI Provider API Key。
- VS Code 扩展新增浏览器设备码登录，LDAP 密码只提交到 ChipMate Server 网页；扩展仅按 Server 来源隔离保存短期访问令牌和单次轮换刷新令牌。
- 新增独立的市场登录、退出、过期刷新、Server 地址切换和撤销状态；受保护请求遇到 401 时最多刷新并重试一次。
- 配套 ChipMate Server 1.2.1 提供 LDAP BindDN 配置测试、加密凭据、历史身份映射、管理员与受限用户过滤、应急管理入口及认证审计。
- LDAP 配置变更会撤销旧网页和插件会话；AD 管理员权限变化会在后续目录复核时同步生效。
- 旧 New API 人员认证接口不再回退，旧客户端的受保护写操作会收到明确的升级提示；公开目录、下载、渲染和更新接口保持可用。
