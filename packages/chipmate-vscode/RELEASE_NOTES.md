# ChipMate 1.2.25

相较 1.2.24，本次手动验证候选修复自定义 Qwen FIM 补全模型选择：

- 在设置页选择已连接的 OpenAI-compatible 提供商模型，保留模型原名、部署别名和完整 ID；列表缺少模型时可先在提供商设置中添加。
- 已选模型不可用时保留原配置并提示；切换模型、断开连接或刷新提供商目录时取消旧请求并清理补全缓存。
- 自定义模型使用 Qwen FIM 模板，后端按模型配置向上游发送真实 API ID；内置补全组合和自动策略保持原有行为。
- 本候选按当前工作树构建，包含其他尚未逐项完成目标机验收的开发改动。Linux x64 和 Windows x64 均仅供手动验证，不进入自动更新渠道。
