Search all indexed documents—including the current workspace and explicitly approved external directories—by semantic meaning and return ranked snippets with source references.

## When to use

- Answer questions about configured PDF, DOCX, XLSX, ODS, Markdown, CSV, TSV, RST, or text documents
- Find policy, design, specification, spreadsheet, or report content stored outside source code
- Retrieve document evidence with page, sheet row, or line references before answering
- When the user explicitly asks to consult, search, or answer from indexed documents or an approved external directory, call this tool before answering
- Limit document search to one configured workspace subdirectory or approved external directory with `path`

## When NOT to use

- Search source code snippets — use `semantic_search` or `codebase_analysis`
- Read a known local file directly — use `Read` or the file-specific readers
- Search external documents that the user has not explicitly approved for indexing

## Constraints

- Omit `path` to search every configured document root, including the workspace and all approved external directories configured for indexing.
- Use `path` only for workspace subdirectories or approved indexed external paths.
- Treat answers as ungrounded unless the returned snippets include source references.
