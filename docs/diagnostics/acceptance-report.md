Storybook 提交使用视觉夹具，不执行上传。因此当前证据是“真实组件交互”“正式客户端处理器与 HTTP”“真实 Server 接收及管理页”分别验证，尚未形成真实 VS Code 点击入口直达 Server 的单次完整安装验收。
