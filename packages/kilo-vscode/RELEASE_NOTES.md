# ChipMate 1.0.20

相较 1.0.6：

- 修复 DeepSeek V4 调用 Skill 创建、安装、发布和事务工具时被参数 Schema 阻断的问题。
- 重构设置页分组导览与窄宽度选择器，保留全部设置项、原有路由和保存逻辑。
- 重新设计 QA 对话中的标准工具调用框，并统一修正强调线、工具图标与标题的视觉顺序。
- OpenAI-Compatible 索引仅在明确支持可变维度的 Qwen3 固定模式发送 `dimensions`；bge-m3 等模型保留维度用于建库和返回长度校验，但不再发送不兼容的 Matryoshka 参数。
- 修正 RAG 嵌入配置校验错误过于笼统的问题，保留脱敏后的 HTTP 状态、服务端详情以及 provider、模型和维度上下文。
- 修复主工作树被错误识别为关联工作树、导致代码图完成后 Code RAG 持续等待主索引的问题。
- 文件监控不可用时继续完成全量索引并提示手动重建，不再把 watcher 初始化失败升级为整个索引失败。
- 精确符号检索复用 CodeGraph 词法证据，优先返回函数定义，避免向量候选遗漏实现文件。
- 新增 Ultra Agent：冻结一份 Code 基准答案，由三个独立只读 Explore 会话并行验证，最后通过独立 Ask 会话综合答案。
- 在进入 Ultra 的阻断式提醒中展示冻结 Code 答案、三路验证与独立 Ask 综合会话。
- 新增 PlantUML 生成、服务端渲染、语法诊断与 PNG 回传能力；明确区分 Mermaid 与 PlantUML 的工具路由。
- 加强 Mermaid 图表的语义一致性保护，阻止修复、拆图或 Word 适配过程中丢失节点、关系与关键事实。
- 完善 ChipMate Server 的 PlantUML endpoint 状态、健康检查与设置页布局，敏感 URL 信息不会直接暴露。
- 更新检查现在可展示服务端发布说明，并使用短期候选标识防止过期或伪造的安装请求。
- VSIX 现在强制携带与版本匹配的 `RELEASE_NOTES.md`，缺失或版本不一致时打包直接失败。
- 强化 ChipMate 身份与默认简体中文交互策略，同时保留命令、路径和兼容性标识原文。
- 将工作状态行中的 Liquid Glass 加载动画放大至 24px，提高浅色与深色主题下的辨识度，同时保持按钮内紧凑加载状态不变。
- 增强四种 Liquid Glass 加载动效：Orbital 使用 96 帧三轴厚壁玻璃陀螺渲染，Signal 与 Prism 改用刷新率同步的合成动画，Liquid 提升至 108 帧，减少低帧感与循环接缝。
- 修正真实加载生命周期中的动画分布偏置；Orbital 在 24px 状态行中固定横向、纵向和斜向三轴骨架，让独立环面高光沿闭合轨道运动，并保留中心球与可信前后遮挡。
- 修正多个会话并行加载时复用同一种动画的问题；每个会话生命周期独立绑定动画，同一轮重挂载保持稳定，新一轮继续按四种一袋轮换。
