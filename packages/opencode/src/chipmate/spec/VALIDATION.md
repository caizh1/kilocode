## Mac 与官方 DeepSeek 实测

- 在隔离用户目录中安装真实 VSIX，确认 `chipmate.chipmate` 版本 1.2.13、平台 `darwin-arm64`，被测扩展以安装态激活，14 个必要命令存在。
- 隔离测试只启用指定 DeepSeek Provider；最终包复测关闭其他模型目录的联网拉取，避免外部初始化等待。未为测试修改普通 QA 实现。
- 使用官方 DeepSeek Flash，分别验证源码后端和安装包后端的普通算术问答、详设讨论、引用 `/spec` 示例、普通“继续”、实际文件读取、错误模型拒绝后继续 QA。没有创建 Spec 任务，也没有修改 QA 默认模型；请求观察记录未发现 Spec 阶段资源混入系统提示。
- 使用仅存在于忽略目录的测试适配器，为 Spec 注入真实 DeepSeek 接口。合成的常量函数样本完成 6 次模型调用、3 次真实问题服务确认、实际 C 编译、独立断言运行、交付及后续 QA。适配器不进入测试包，任务如实记录 DeepSeek，生产模型工厂仍要求 Qwen3.8-27B。
- 实测发现七类约束名称和计划条款编号没有完整编码进模型结构；已改为固定约束枚举与数量，以及按真实条款生成编号枚举。运行时证据、覆盖率和批准校验继续保留。
- 保留首次超时、HTTP 503、结构不合格及 Pro 复述结构定义的失败证据。这些执行均暂停，没有把错误输出当作有效基线或计划。成功样本不代表模型对真实固件的质量已达标。
- 提供的测试凭据只用于隔离测试进程，未写入源码、配置明文或交付包。测试日志、适配器、样本和结果保存在本地忽略目录 `.chipmate/qa/spec-macos/`。
