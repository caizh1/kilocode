# ChipMate Server 1.2.5

相较 1.2.4，新增内网私有诊断日志接收和管理，配合 ChipMate 1.2.20 使用。

- 上传复用 LDAP 设备授权，服务端依据认证身份登记提交人；普通用户仅查看本人记录，现有管理员可查看全部。
- 新增能力声明和诊断上传、查询、下载接口，校验 ZIP 清单、大小、路径及 SHA-256，支持同一提交编号的幂等查询。
- 新增“诊断日志”页面，可按编号、提交人、时间、版本及平台筛选，查看摘要、采集完整度并下载。
- 日志包及摘要保留 7 天，到期拒绝访问并后台清理；默认最多 4 个并发上传、10 GiB 存储预算，沿用低磁盘保护。
- 升级前备份既有持久数据目录及认证密钥；启动自动执行数据库第 12 号迁移。保留原数据卷和权限，不重新初始化 LDAP 或管理员。
- 先升级 Server，再安装客户端。源码与本机集成验证通过；真实 Chrome、内网 LDAP、目标机和实际效率指标仍待验收。
