# ChipMate 1.2.19

相较 1.2.15，本次为 1.2.19 累计更新重打包，包含以下变化：

- 新增“未来风”皮肤，在“设置 → 显示”手动启用电青与洋红双色霓虹边框、会话标签和输入框；覆盖插件自绘页面，提供关闭、柔和、沉浸动效，保留原皮肤为默认并遵循减少动态效果设置。
- 输入工具栏支持文件、图片、编辑器选区和文件夹引用，可查看、移除上下文；底栏按模式、模型、推理档位排列，支持窄侧栏、长模型名和多会话标签。切换皮肤保留输入组件和会话状态，忽略切换草稿或修改输入后的迟到引用结果。
- 收紧未来风空输入框高度，按容器宽度切换紧凑单排或双排底栏；上下文改为引用图标与数量。页面、输入框和当前标签使用独立细线霓虹素材，移除侧栏重复导航，并修复分栏设置导航文字隐藏与弹层过大问题。原版继续作为安装和升级默认，已手动保存的皮肤选择保留。
- 修复未来风点击新建会话或历史入口时切走聊天侧栏的问题；恢复模型后直接可见的推理档位，不再由上下文控件占据第三个选择器位置。
- 将 `/spec` 简化为在当前对话中按需加载的 SDD Skill，跟随当前模型选择，移除专用阶段调度、预算检查和批准状态机；取消固定文档工具、图页数量和强制子任务要求，保留来源证据、中文任务材料及基线、计划、交付三次确认指引。已有显式模型覆盖继续生效，旧任务保留为历史资料。
- 修复远程连接两端时钟不一致导致 Spec 流程介绍打不开的问题，增加加载、失败原因和重试反馈，并保持取消、迟到响应和重复打开的隔离。
- 新增独立 `word_to_images` 工具，将已有 Word 按页转为 PNG 以查看公式、流程图和复杂表格；页面卡片显示真实页码并使用原生图片预览。该工具不修改原 Word、不走旧目录刷新或页码回填流程，需要支持独立转图接口的 ChipMate Server。
- Linux x64 包内置 PDF 文本提取程序、运行依赖和中文编码数据，修复缺少 `pdftotext` 导致 PDF 文档索引不可用的问题。
- Windows/Linux 为手动验证候选包，不进入自动更新渠道。真实目标机安装、完整原生引用发送及模型遵循仍待验收；既有低配启动长任务超标继续单列，不以构建通过代替业务验收。
