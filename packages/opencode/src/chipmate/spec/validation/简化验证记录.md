# Spec SDD 简化验证记录

日期：2026-09-08。环境：当前 macOS 源码工作区；不代表内网 Qwen、Windows 或远程 Linux 安装环境。

## 实现与人工基线

本轮用户目标是只保留 SDD 流程与原则，阅读、检索、图文理解和分工方式由模型自行决定。使用者为依据已评审详设工作的固件开发人员。输入仍需要明确工作范围、可访问设计资料与相关代码。

原指引明确要求 Word 结构检查、按需转图、固定读图子会话及图页数量。现移除这些操作编排，保留三次人工确认、来源与疑点、真实验证和恢复材料。主 Skill、三份参考和五份模板共九份内嵌资源；旧版十三份内嵌资源共 11106 字符，新版共 4481 字符。这是资源文本统计，不是请求 token 或人工耗时降幅。

本轮改动位于 Spec 指引、资源加载清单、相关测试、说明和 changeset。命令入口、原生 question 展示与回答、工具实现、Server、模型和压缩实现未修改，未修改版本或打包发布。

资源缓存继续按内容哈希生成；三份阶段参考和五份模板的真实文件与引用均已核对，并验证并发准备、损坏缓存恢复和失败时不注入半份指引。旧任务文件保持原样，新加载目录不包含退役图页资源。

浏览器确认测试使用当前源码的原生命令与工具执行、真实消息记录、现有扩展处理器及 HTTP 路由，展示载体为 Storybook 中的实际组件。消息转交使用测试桥接，不是实际 VS Code 扩展宿主的端到端安装验收。反例保留真实 question 请求但移除其关联工具消息，卡片不能展示；恢复的是原执行链产生的消息，没有补造工具消息。

图页测试使用已存在的小图片和脚本化 Provider，验证标准阅读工具向模型请求传递图片及可选任务委派，不证明 Word 转换或语义理解。三张图片是测试数据，不是新版默认数量。
