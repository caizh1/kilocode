## 实现与隔离

主会话按需读取图页阅读参考资料，通过现有 `word_to_images` 准备图片，再由原生前台 `task` 新建子会话读图。每批默认一页、最多两页，不复用 `task_id`；大单元跨批保存连接关系。主文件不注入全部参考资料。新增资源仍按内容哈希缓存，仅显式执行内置命令时准备。

交接要求实际读取全局背景、局部原文和关联依据，并允许补读授权原文。子任务分段保存完整证据，不用通知字数限制内容；主会话按章节读完证据并对照正文。关键图表由新子会话先独立提取，再比较旧记录。建立任务前、实现任务前重新读对应完整证据。

生产改动仅在 `src/chipmate/spec/`。未增加普通 QA 分支，未修改 Server、模型配置、原生 task/read/question、权限或压缩实现。测试辅助层增加真实权限与文件锁服务，只有读图测试使用；普通命令测试保留原服务集合。三次确认仍使用正常 question，Skill 不是强制阶段门禁，也不是强制图片数量门禁。

## 固定质量样本及待执行反例

`test/chipmate/spec-image-document.ts` 生成合成三十页 DOCX，用于稳定复现上下文关联与长文档输入。不是人工评审的 UFS 规范，不替代真实项目。可在 CLI package 中调用导出的 `specImageDocument()`，将字节保存到本地 `.runtime`，再通过真实转换接口取得页面。

评分依据留在评测人员侧；执行被测模型时仅提供 DOCX 及授权的任务材料，不把生成器或此答案表放进被测工作区。合成文档包含引导语，属于机制样本，后续盲评必须使用自然表述的真实详设。

| 样本 | 独立评分依据 | 反例及验收要求 |
|---|---|---|
| 第 1、2、6 页：前章定义及跨页连接 | ACK 表示停止并排空；STOP_REQ 仅是请求；ACK 否定分支保持占用并续接 X；第 6 页等待 RESET_DONE，再释放 | 只交第 2 页时须补读第 1、6 页文字或报告缺口；删除否定分支或 X 续接后，复核须指出具体遗漏 |
| 第 3、5 页：寄存器脚注 | R0 偏移 0x20、位 0 DONE、默认 0；W1C、写 0 不变、读取不清除；仅初始化后适用 | 删除写 0、读取不清除或初始化前提，复核须找到原文并指出语义变化 |
| 第 1、4 页：公式与单位 | T_total=N×T_cycle；N=4，T_cycle=25 us；推导结果 100 us 与原文表达式分开记录 | 删除单位或符号来源，不能判为完整；补读仍缺少前提时明确缺口 |
| 第 7 页：确实缺少停止条件 | 另一模块的立即回收约定缺少停止握手依据 | 不自动套用前一模块 ACK 定义；指出停止与缓冲区复用的实际影响 |
| 第 8 页：正文与图冲突 | 正文允许无确认释放，图仍要求 ACK | 保留两处来源，主会话提出设计决议，不能静默选择一个 |
| 第 9 页：模糊数值 | 栅格数值已重度模糊，转换后肉眼不可辨认 | 记录数值不可读；不猜值。已查看实际 PNG；未测试真实模型是否拒绝补猜 |
| 第 10—30 页：累积压力 | 引用同一流程，每页另有限定请求的缓冲区约束 | 主会话须读回每批完整记录；不能因重复图而省略该页新增约束 |

对每个删除反例，使用独立的新子会话：先从原图和必读原文保存提取，再读取删减记录比较。不能只搜索模板字段是否存在。当前尚未执行这些真实模型语义反例，不能写成“遗漏检测通过”。

第 9 页最初使用 SVG 模糊滤镜，真实 LibreOffice 转换忽略了滤镜，数值仍清晰；已改为预先模糊的 PNG 并重新转换、查看。这说明文件结构通过不能替代页面检查。

## 真实质量对照的记录方法

目标用户为固件详设阅读与开发人员。输入需为已评审 DOCX、明确范围、支持图像的实际子任务模型、可用转换服务及授权目录。资料缺失、视图不可辨认、模型不支持图像或权限拒绝时只报告缺口，不承诺完成图页理解。

在同一份人工标注的长详设上对比旧主会话读图和新方案。冻结源文件哈希、人工原子条目、关键性、各条页码及允许的推导；记录实际主/子模型配置、每个模型请求输入 token、每会话峰值、总调用数、转换和模型耗时、阅读/答疑/核对/纠错人工分钟数。使用服务实际 token 统计，不按字符数臆算图片 token。保存完整模型请求的元信息和证据路径，敏感资料保持本地。

统计：完整性为正确保留条目数/全部标注条目数；准确率为正确且有依据的事实数/输出事实总数；关键漏项单独逐条核对。目标是固定标注样本关键遗漏为零，所有本次范围图页都有阅读及核对记录，并统计上下文峰值和耗时变化。若引入复核后总调用增加，应如实记录，不能只报告父会话图片减少。

当前机器没有目标 Qwen 和人工标注长详设，语义完整性、准确率、关键漏项、实际 token 峰值与耗时对照均未验证，不宣称减少人工 80%。目标环境验收沿用根目录 DEV-014。
