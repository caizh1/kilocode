# 第三方方法来源记录

Patent Radar v2 只参考下列公开项目的方法论，不加载其 Skill，不复制其提示词、源码或文档文字，也不捆绑额外 sidecar：

- `Obviously-Not/patent-skills` 的 Code Patent Scanner：参考“实现细节抽象为核心机制”和“问题—方案—效果”组织方式。仓库声明 MIT License。
- `Obviously-Not/concept-scanner`：参考逐文件提炼、全局合成和 bridge 探索方式。仓库声明 Apache-2.0 License。
- `soarsky1991/evidence-first-patent-skill`：参考证据等级、来源哈希和人工门禁思想。
- `abhirajthakur/provenance`：参考生成后独立回查原文的思想。

实际实现全部位于 ChipMate TypeScript 代码中。任何将来的源码或文字复用必须重新核对具体提交的许可证，记录版权归属并更新产品第三方声明；当前记录不授权直接复制外部内容。
